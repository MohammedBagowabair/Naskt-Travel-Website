# naskt.

موقع تجريبي لوكالة سفر خيالية. العلامة **naskt.** / **نسكت** ليست شركة حقيقية، والأسعار والعروض والفريق والمخطط للتوضيح فقط. التواصل في الصفحة يذهب إلى واتساب.

لا حاجة إلى بناء. افتح `index.html` أو انشر المجلد كما هو. GitHub Pages يخدم فرع `main` من الجذر.

- العربية هي اللغة الافتراضية (اتجاه من اليمين). زر **EN** في الشريط يبدّل كل النص ويحفظ الاختيار.
- صور WebP من Unsplash وPexels وWikimedia Commons. التفاصيل في [credits.html](credits.html).
- ملاحظات التصميم في [DESIGN.md](DESIGN.md).
